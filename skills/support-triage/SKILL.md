# 技术支持排查流程

1. 收集产品、版本、实际现象、期望行为、影响范围与最近变更。
2. 检索相应产品和版本的文档；保留文档标题、章节与原文证据。
3. 只把日志规则匹配当作线索，提出有序、可验证的排查建议。
4. 演示监控必须标为模拟数据；用户尚未执行的操作不能写成已完成。
5. 缺少依据时继续追问，不编造日志、监控或根因。
6. 用户要求升级时整理工单草稿，说明尚需用户在界面确认。
7. 确认创建后使用真实工单编号跟进。权限与状态变更由业务服务校验。

不要收集密码、API key、完整数据库凭据，也不要建议绕过资源授权。
